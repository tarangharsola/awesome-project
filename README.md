{"# Collaborative Code Editor Web Application

## Local Run Steps

1. Clone the repository.
2. Run `npm install` to install dependencies.
3. Run `npm start` to start the development server.
4. Open your web browser and navigate to `http://localhost:3000`.

## Features

* Real-time collaboration
* Syntax highlighting for JavaScript, Python, and HTML
* Live cursor tracking
* Active users panel
* Document sharing
* User identification

## Technical Requirements

* Use established libraries for operational transformation or CRDTs to handle conflict resolution
* Implement WebSocket or similar real-time communication protocol
* Choose an appropriate code editor component that supports extensions and overlays
* Ensure proper error handling and reconnection logic
